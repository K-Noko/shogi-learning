# 設計書: アプリケーション層

設計書の読み方は[`overview.md`](overview.md)を参照。外した案・経緯・長い論証は[`rationale/application.md`](rationale/application.md)に、同じ見出しで置く。

## 位置づけ

- アプリケーション層は、ドメインの対局（[`domain.md`](domain.md)「対局」）を使って、対局を進める層。APIの層の内側、ドメインの外側にある（[`overview.md`](overview.md)「全体のアーキテクチャ」）
- ゲームのルールは持たない（ドメインが持つ）。HTTPの受け答えも持たない（APIの層が持つ）。持つのは、外の世界とのやり取り（人間の入力を待つ、Botに問い合わせる）と、対局の保持

## APIの層との境目

- **アプリケーション層は、外側が必要とする操作だけを見せる**。APIの層はこの操作だけを呼び、入れ物の中に何が入っているか（ドメインの対局か、それを包むGameSessionか）をたどらない
  - 対局を作る（開始局面から対局を作り、IDを振って入れ物に登録し、対局を返す。`POST /api/games`を作るときに足す）
  - IDで対局を引く（見つからなければ例外を投げる。APIの層はそれを`404`に変える）
  - 人間の着手を受け付け、人間の手番に戻るまで進める（着手を扱うようになったら足す）
- 最初の機能（初期盤面）では「対局を作る」操作を作らない。サーバーの起動時に、アプリケーション層がIDを`test`と採番し、ドメインに平手の盤と対局を作らせて入れ物に登録する（スタブ）。スタブは「対局を作る」操作を足すときに撤去する
- **IDを採番するのはアプリケーション層、IDを持つのはドメインの対局**（[`domain.md`](domain.md)「対局」）。入れ物のキーには、対局自身が持つIDを使い、IDの出どころを1つにする
- 境目を中身の構造ではなく操作で決めると、アプリケーション層の中身の変更（例: 入れ物の中身を対局からGameSessionに替える）がAPIの層に波及しない。そのため、アプリケーション層の中の決定は後から安く覆せるので、今の時点で一番シンプルな形を選べる

## GameSession

- **GameSessionは、1つの対局を進める**。`run()`ループで、今の手番のMoverに次の手を問い合わせて待ち、返ってきた着手をドメインの対局に適用する
- GameSessionは、人間とBotを区別しない（`if is_human:`のような分岐を入れない）。どのMoverも同じ形で待つ（[`overview.md`](overview.md)「内部の仕組みとクライアントへの届け方を分ける」）
- 着手が合法かどうかは、GameSessionではなく、ドメインの対局の着手の適用が確かめる（最後の防衛線。[`domain.md`](domain.md)「合法手の判定の置き場所」）
- **GameSessionは、Moverと着手が生まれるときに作る**。初期盤面を表示するだけの段階ではMoverも着手もないので、GameSessionを作らず、対局の入れ物はドメインの対局をそのまま保持する。着手を扱うようになったら、入れ物の中身を「対局」から「対局を包むGameSession」に替える。対局そのものは捨てずにそのまま使う

## Mover

- **Moverは「次の手をくれる出入り口」**。GameSessionは、手番のMoverに次の手を問い合わせるだけで、その手が人間から来たのか、Botが決めたのかを知らない
- Moverの実装
  - 人間用: APIの層から届いた人間の着手を、GameSessionに渡す。外からの入力をどのMoverに届けるかを判定するのは、APIの層だけ
  - `RandomMover`（Phase1）: ルールのモジュールで合法手を列挙し、その中からランダムに選ぶ
  - USIエンジン（Phase2）: 別プロセスのエンジンとやり取りする実装として、同じ出入り口に差し込む

## 対局の入れ物

- **IDから対局（またはGameSession）を引く入れ物を、アプリケーション層に置く**。対局の保持と検索はゲームのルールではないのでドメインには置かず、HTTPの受け答えでもないのでAPIの層（ルーター）とはファイルを分ける
- メモリの上の辞書（IDから対局への対応）で持つ。複数の対局の管理の本格的な作り込みは、Phaseが未定（[`overview.md`](overview.md)「ロードマップ」）
- 古い対局の片付けはPhase1では行わない（`debt`。[`api.md`](api.md)「新規対局とリセット」）
